# Airplane — Flight Delay Classification & Data Quality

> **핵심 질문:** 불완전한 항공편 데이터에서 값을 억지로 채우지 않고, 무엇을 알고 있는지 보존하면서 공정하게 모델을 비교할 수 있는가?

- **Repository:** https://github.com/Peter-jackson12/Airplane
- **Focus:** 데이터 품질 · 결측 처리 · 누수 방지 평가 · 분류 모델 · 외부 데이터 확장
- **Stack:** Python · Pandas · LightGBM · scikit-learn · Cross Validation

## 1. Problem
원본 100만 행 항공편 데이터에는 항공사 식별, 시각, 연도, 라벨 범위 등 모델링 전에 해결해야 할 의미 문제가 있었습니다. 단순히 결측을 채우거나 점수를 높이는 것보다 **관측값과 추정값을 구분하고, 검증 데이터가 모델 선택에 섞이지 않는 평가 구조**를 만드는 것이 핵심 과제였습니다.

## 2. Data & Constraints
- 원본: 1,000,000행 × 19열
- 라벨이 있는 행: 255,001개 / 미라벨: 744,999개
- 라벨 중 지연: 45,000개
- 연도가 직접 제공되지 않아 외부 BTS 데이터와의 대조가 필요했습니다.
- 현지 HHMM 차이는 시간대 보정 비행시간으로 해석할 수 없습니다.

## 3. Approach
1. 항공사 코드와 이름이 유일하게 대응할 때만 결측을 대치했습니다.
2. 미상 시각을 임의의 정오 같은 정상 값으로 바꾸지 않고 NaN과 결측 플래그로 보존했습니다.
3. 복원한 값과 원래 관측값을 구분할 수 있도록 결측 이력 피처를 유지했습니다.
4. outer validation과 inner holdout을 분리하고, 타깃 인코딩도 학습 경계 안에서 계산했습니다.
5. 외부 BTS 자료와 12개월 단위로 대조해 단일 후보가 충분히 뒷받침되는 행만 날짜 귀속에 채택했습니다.

## 4. Validation
전처리 변경을 한꺼번에 비교하는 것뿐 아니라 개별 변경 조건도 포함해 **10조건 × 3시드 × 5-fold = 150개 outer fold**를 평가했습니다.

- 트리 수: inner holdout LogLoss로 선택
- 분류 임계값: inner holdout Macro F1으로 선택
- 최종 점수: outer validation에서 평가
- pooled OOF 기준으로 시드별 결과를 비교

## 5. Result
전처리의 의미와 평가 구조는 개선됐지만, 분류 성능 향상은 확인되지 않았습니다.

| 조건 | Macro F1 평균 | LogLoss 평균 | ROC-AUC 평균 |
|---|---:|---:|---:|
| P4 | 0.574916 | 0.448016 | 0.641194 |
| P4_clean | 0.574541 | 0.448216 | 0.640596 |
| P6_fixed | 0.576062 | 0.447597 | 0.642757 |
| P6_clean | 0.575685 | 0.447577 | 0.642804 |

따라서 `clean` 경로를 “성능이 개선된 모델”로 주장하지 않고 **의미가 더 정확한 전처리 경로**로 구분했습니다.

외부 자료 대조에서는 완전 지문과 단일 후보 연도를 만족한 **706,759행(70.68%)**만 날짜 귀속에 채택하고, 나머지 293,241행은 보류했습니다.

## 6. What I Changed / Learned
처음에는 결측을 더 많이 채우고 파생 변수를 늘리는 것이 개선이라고 생각하기 쉽지만, 실제 검토에서는 일부 대치가 행 순서나 모호한 코드 대응에 의존하고 있음을 확인했습니다.

그 결과 목표를 “결측률 감소”에서 **값의 의미와 추정 근거를 보존하는 전처리**로 바꿨습니다. 성능이 오르지 않았어도 검증 가능한 데이터 계약을 얻었다는 점을 별도의 결과로 남겼습니다.

## 7. Limitations
- 현재 점수는 정적 데이터 묶음의 교차검증 결과이며 실제 미래 출발 전 예측 성능을 입증하지 않습니다.
- 전체 입력 묶음의 일부 통계를 활용하므로 실서비스 시점의 정보 가용성 계약은 별도 검증이 필요합니다.
- 날씨 정보를 추가한 최종 성능 비교는 아직 진행 중입니다.

## 30-second Summary
100만 행 항공편 데이터의 결측과 식별 문제를 바로 모델에 넣기 전에 데이터 의미부터 검증한 프로젝트입니다. 모호한 대치를 제거하고 관측/추정 이력을 보존했으며, 모델 선택과 최종 평가 데이터를 분리한 교차검증 경로를 구성했습니다. 전처리는 더 타당해졌지만 Macro F1은 개선되지 않았고, 그 사실을 그대로 결과로 남긴 뒤 외부 날씨 정보라는 새로운 정보원 검증으로 확장하고 있습니다.
