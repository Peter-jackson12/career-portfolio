## 다음 우선순위
1. **P0:** Stock/Airplane의 개인 프로젝트·end-to-end·AI-assisted ownership은 확인됐습니다. 다른 프로젝트 역할·세부 attribution·목표 직무와 전체 Git 이력의 공개 가능성을 별도로 점검합니다.
2. **P1:** 대표 프로젝트의 새 결과가 원본에 반영되면 고정 revision·근거·한계를 함께 갱신합니다. 의미 검토 없는 자동 요약은 하지 않습니다.
3. **P1:** 실제 공고 하나에 대한 Agent 준비 메모를 검토하고, 근거가 연결된 이력서 문장으로 수동 압축합니다.
4. **P2:** finance는 개인 역할·재현 절차·과장 없는 결과가 정리된 뒤 별도 상세 사례로 승격합니다.
5. **P2:** 콘텐츠 안정화 후 GitHub Pages 반응형 화면·접근성·실제 모바일 검증을 추가합니다. 공개 승인이 선행돼야 합니다.

## 보류한 확장
영문은 한국어와 다른 성과를 만들지 않도록 동일 근거 ID를 재사용하는 별도 표현 레이어로 검토합니다.
지금은 두 언어의 긴 문서를 복제하지 않습니다. PDF 이력서, Contact 영역, 자동 배포는 이번 범위가 아닙니다.
템플릿을 통째로 포크하지 않고 기존 Markdown 기반 허브를 유지합니다.
