# 공개 전 개인정보 점검

## 현재 경계
이 저장소는 공개용 자료를 작성하지만 접근 설정은 비공개로 유지합니다.
연락처·실명·주소·생년월일·이력서 원본·지원 이력·API key·토큰은 추가하지 않습니다.
Agent의 실제 입력과 출력은 Agent의 Git 제외 `private/` 또는 저장소 밖에서 관리합니다.
여기에 private 디렉터리를 만들더라도 개인정보 보관 장소로 사용하는 것은 권장하지 않습니다.

## 보호 장치와 한계
허용 필드 계약, 민감 문자열 검사, .gitignore, tracked-file 검사를 함께 둡니다.
검사는 대소문자 경로 우회와 Git symlink 모드도 거부하고 전각 문자를 정규화합니다.
.env.example은 비민감 예시만 허용하며 그 내용도 검사합니다. 이메일·국내 휴대전화·일부 토큰 형식은 검사하지만 이름·주소·변형된 비밀값을 모두 탐지하지 못합니다.
Git 제외 규칙은 이미 추적되거나 과거 커밋에 들어간 내용을 제거하지 않습니다.
이번 작업은 저장소 공개 전환이나 Git 이력 재작성을 수행하지 않습니다.

## 공개 승인 전 수동 점검
현재 파일뿐 아니라 모든 브랜치·과거 커밋·PR·Actions 로그와 artifact를 검토합니다.
커밋 작성자·서명 metadata에도 연락처가 포함될 수 있으므로 웹 화면의 파일 검사만으로 끝내지 않습니다.
새 커밋의 작성자 설정과 GitHub 이메일 공개 설정도 확인합니다. 기존 이력 수정은 별도 계획과 승인이 필요합니다.
원본 repository 링크의 접근 권한·데이터 이용 조건·타인의 정보도 확인합니다.
개인 담당 범위와 팀/AI 도구의 기여를 확인한 뒤에만 채용용 문구를 확정합니다.

검증 성공은 공개 승인이 아닙니다. 자동 게시·자동 배포·연락처 수집 기능은 없습니다.
