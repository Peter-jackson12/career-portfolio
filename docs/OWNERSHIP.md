# Stock · Airplane: 작성자가 확인한 프로젝트 책임

## 확인 사실과 출처
2026-09-22 사용자가 이 커리어 시스템 정리 작업에서 직접 확인한 사실을 반영했습니다.
**Stock과 Airplane은 팀 프로젝트가 아닌 개인 프로젝트**이며, 작성자가 두 프로젝트의 전체 ownership을 가집니다.
표현은 **Personal Project / End-to-End Project Ownership / AI-Assisted Development**입니다.
이 사실의 출처는 작성자 진술(`owner_statement`)이며 커밋 수나 AI 이름을 보고 추론한 것이 아닙니다.
원본 README의 과거 `TF` 표기나 AI 도구의 커밋 참여를 팀 프로젝트의 증거로 삼지 않습니다.

## 작성자의 책임
문제 정의와 목표 설정, 연구·개발 방향, 아키텍처·데이터 흐름과 기술적 판단을 책임집니다.
기능 구현 방향과 코드 통합, 검증 전략과 테스트·결과 검토 방향, 운영·우선순위·문서화,
프로젝트의 최종 의사결정도 작성자의 책임입니다.
Stock에서는 원본 수집·입력 품질·qualification·replay의 단계 구분과 운영을,
Airplane에서는 전처리·평가·외부 데이터 확장의 방향과 결과 해석을 이 책임 범위로 설명합니다.

## AI 개발 도구의 역할
ChatGPT·Claude와 Codex/Claude Code를 적극적으로 활용했습니다.
코드 작성·리뷰·디버깅·테스트 작성·설계 검토·문서 작성·리팩터링·조사와 아이디어 검토의 보조 도구입니다.
무엇을 시킬지, 어떤 결과를 채택할지, 검증 기준과 설계 방향을 어떻게 정할지,
최종 결과를 어떻게 프로젝트에 통합할지는 작성자가 통제했습니다. AI 사용은 ownership 미확정의 사유가 아닙니다.

## 세부 주장과 성과의 경계
이번 확인으로 특정 코드 한 줄이나 특정 테스트를 직접 타이핑한 사람,
특정 로컬 실행의 실행자, AI 생성 코드 비율까지 확정하지 않습니다. 관련 수치를 새로 만들지 않습니다.
Stock 수익성·실주문 성과·전체 raw 합격, Airplane 날씨 효과·미래 운영 성능은 기존 evidence의 범위를 따릅니다.
프로젝트 책임이 확정됐다고 미완료 실험이나 검증되지 않은 성과가 완료되는 것은 아닙니다.
기존 근거 한계의 “단독 구현 기여를 주장하지 않는다”는 모든 코드를 혼자 직접 작성했다는 주장에 관한 한계입니다.
개인 프로젝트의 전체 책임이 미확정이라는 뜻이 아닙니다.
개인적인 발견 일화·비공개 경력·사업 효과도 이 확인으로 생성하지 않습니다.
finance 등 다른 저장소의 역할은 이번 확인 대상이 아닙니다.

## 파일 반영 현황
공개 JSON은 `career-public/v1.1`의 `owner_confirmed`와 ownership 객체로 이 확인을 기록합니다.
생성 인덱스와 Agent의 JSON/Markdown 준비 메모도 같은 프로젝트 책임을 보존합니다.
My Role의 기존 marker·확인일·책임 표기와 구조화 데이터가 다르면 인덱스 생성 전에 실패합니다.
확인되지 않은 다른 프로젝트는 계속 `owner_review_required`이며 이름으로 자동 승인하지 않습니다.
기술 근거·숙련도·직무 자격·evidence 검증은 별도로 판단합니다. CI와 원격 반영 상태는 각 PR 기록을 따릅니다.
