# 표현·디자인 기준

## 목적과 읽기 순서

채용 검토자가 대표 프로젝트의 문제, 검증한 결과, 남은 한계와 원본 근거를 빠르게 찾도록 한다.
README는 소개 → 대표 프로젝트 → 결과 기준 → 개발 방식과 근거 → 다른 분석과 학습 순서로 읽는다.
운영 문서는 접을 수 있는 별도 영역에 둔다. 사례 본문의 필수 제목과 ownership/status 표시는 유지한다.

## 표현 토큰

| 역할 | 값 | 적용 |
|---|---|---|
| Paper | `#FBF8F0` | 헤더 배경 |
| Ink | `#304750` | 헤더 주요 문자 |
| Muted | `#61727A` | 보조 표현 예약 색 |
| Accent | `#356A86` | 얇은 선 |
| Rule | `#D7DCD9` | 구분선 예약 색 |
| Canvas | 1600 × 480 | 헤더 SVG viewBox |
| Type | Arial / Helvetica / sans-serif | 라틴 문자, 시스템 대체 글꼴 |
| Korean type | Noto Sans KR / Apple SD Gothic Neo / Malgun Gothic / sans-serif | 한글 대체 글꼴 |

Markdown 본문은 GitHub 기본 글꼴·테마·링크 색을 따른다. 위 토큰이 본문 CSS를 강제하지 않는다.
단일 열, 짧은 문단, 명시적 결과·한계 라벨과 여백을 사용한다.
그라디언트·그림자·배지 묶음·카드 격자·장식 차트·티켓 모티프를 추가하지 않는다.

## 시각 자산

- [Canva 보기](https://www.canva.com/d/Vsd8tKp82C-GXyC) · [Canva 편집 원본](https://www.canva.com/d/gTE2d0MmRfYM91K)
- 저장 자산: [portfolio-header.svg](assets/readme/portfolio-header.svg)
- Canva 원본의 배경·문자 색을 위 Paper·Ink 토큰으로 옮겼다. 글꼴은 외부 의존성 없는 시스템 대체 글꼴을 사용한다.
- Canva 미리보기에서 확인한 레이아웃을 저장소용 정적 SVG로 재구성했다. Canva 직접 export 파일이나 픽셀 단위 복제라고 주장하지 않는다.
- SVG는 UTF-8 텍스트이며 스크립트·외부 이미지·외부 글꼴·추적 코드가 없다. Canva 임시 썸네일 URL을 README에 사용하지 않는다.
- 제목과 부제는 SVG title/desc 및 README 이미지 대체 텍스트에 제공한다. 본문과 프로젝트 링크는 이미지 밖의 실제 텍스트로 유지한다.
- GitHub 일반 본문 폭과 좁은 화면에서 가로 스크롤 없이 읽도록 한다. 이미지 내부의 작은 부제만으로 의미를 전달하지 않는다.
- 자산은 문서 하위에 두어 기존 문서 복사 fixture에 포함되도록 한다. 개인정보 검사를 약화하거나 이미지 지원을 위해 검증 코드를 바꾸지 않는다.

## 사실·접근성 검토

디자인 변경은 성과·상태·분모·고정 revision·개인 책임 범위·AI 보조 개발 공개를 변경하지 않는다.
단위와 한계를 결과 가까이에 유지하고, 미래 운영 성능·수익성·인과 효과를 새로 주장하지 않는다.
프로젝트 사례의 필수 섹션과 근거 링크를 유지한다. 생성 인덱스와 공개 JSON은 표현 변경으로 재생성하지 않는다.

검토 시 README와 두 사례의 GitHub 렌더링, 이미지 대체 텍스트, 내부 이동과 근거 링크를 확인한다.
자동 검사 결과와 실제 화면 확인, 실행하지 못한 검사를 구분해 보고한다.
